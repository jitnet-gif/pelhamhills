# 프로 샵 영수증 인쇄 설정 (2026-09-12)

계산대(`/admin/retail`)의 **Print receipt** 버튼, 매출 탭의 **Reprint receipt** 버튼,
티 시트 예약 카드의 **Payment** 버튼(2026-09-15 추가)은 **브라우저 인쇄**로 영수증을 찍는다.
프로 샵 PC 에 감열 프린터 드라이버만 깔려 있으면 된다. 서버 설정이나 별도 프로그램은 필요 없다.

## 어떻게 찍히나

- 모양은 클럽이 쓰던 Lightspeed 영수증(2026-09-15 실물)을 따른다(2026-09-15 변경): 클럽 로고 →
  클럽 이름·주소·전화 → "Sales Receipt" 와 날짜·시각 → Ticket / Register / Employee →
  Items·#·Price 표 → 오른쪽 정렬 합계(Subtotal, HST, Total Tax, Total) → PAYMENTS → Thank You →
  영수증 번호 바코드(Code 128).
- 내용은 `frontend/lib/retail/receipt.ts` 가 **블록 목록**으로 만든다. 금액은 서버가 돌려준 `Sale` 의
  값만 쓰고, 다시 계산하지 않는다. 바코드는 `frontend/lib/retail/barcode.ts`.
- `frontend/lib/retail/printReceipt.ts` 가 블록을 HTML 로 그려 화면 밖 컨테이너에 넣고 `window.print()` 를 부른다.
- `frontend/app/globals.css` 의 인쇄 규칙이 인쇄하는 동안 나머지 화면을 숨기고 폭을 72mm 로 맞춘다.
- 클럽 이름·주소·전화는 `frontend/lib/nav.ts` 의 `CLUB` 에서 가져온다(주소 줄은 `mailingAddress`).
  바뀌면 거기만 고친다.
- **로고**(2026-09-15 추가)는 클럽 이름 바로 위에 15mm 크기로 찍힌다. 파일은 둘이다:
  `frontend/public/pelham-hills/club-logo.png` 가 클럽 원형 엠블럼 원본(468px)이고,
  `club-logo-print.png` 는 인쇄 크기에 맞춰 360px·64색으로 줄인 것(75KB → 16KB)이다.
  그림은 `frontend/lib/retail/logo.ts` 에 **파일 내용째로** 박혀 있다 — 주소로 걸면 인쇄가
  이미지보다 빨라서 로고 없이 나갈 수 있다. 줄인 사본을 쓰는 이유는 이 그림이 화면 코드에
  그대로 실리기 때문이다(원본을 쓰면 100KB).
  로고를 바꾸려면 두 파일을 바꾼 뒤 이 모듈을 다시 만든다(크기는 `globals.css` 의 `.rc-logo-img`):

  ```
  python -c "import base64,pathlib; d=base64.b64encode(pathlib.Path('frontend/public/pelham-hills/club-logo-print.png').read_bytes()).decode(); p=pathlib.Path('frontend/lib/retail/logo.ts'); s=p.read_text(encoding='utf-8'); p.write_text(s[:s.index('export const')]+'export const RECEIPT_LOGO = \"data:image/png;base64,'+d+'\";\n', encoding='utf-8')"
  ```

  감열 프린터는 흑백이라 색이 회색~검정으로 찍힌다. 엠블럼 테두리의 가는 글자("PELHAM HILLS
  GOLF CLUB")는 15mm 에서 뭉개질 수 있다 — 실제로 뽑아 보고 안 읽히면 크기를 키우거나
  글자 없는 단순한 마크를 따로 만드는 편이 낫다.
- **한 번 인쇄에 두 장이 나간다**(2026-09-15 추가). 맨 아래에 `CUSTOMER COPY`(손님 것),
  `MERCHANT COPY`(프로 샵 보관용)가 찍힌다. 브라우저는 장 사이에서 **페이지를 끊어** 보내지만,
  종이를 자르는 것은 드라이버다.
  **TM-m30III 드라이버의 기본값은 "작업이 끝날 때 한 번"이라 두 장이 이어져 나온다**(2026-09-15 확인).
  한 장씩 잘리게 하려면 인쇄 기본 설정에서 자동 절단을 **페이지마다**로 바꾼다:

  ```
  rundll32 printui.dll,PrintUIEntry /e /n "EPSON TM-m30III Receipt"
  ```

  이 창(또는 설정 → 프린터 → 인쇄 기본 설정)의 문서 설정 / Advanced 쪽에 `Paper cut`(용지 절단)
  항목이 있고, `Each page`·`Per page`·`페이지마다` 로 바꾼다. 항목 이름은 드라이버 버전마다 다르다
  (`Cut each page`, `Auto cut: Each page` 등). 바꾼 뒤 `--kiosk-printing` 창에서 두 장짜리
  테스트를 다시 뽑아 사이가 잘리는지 본다.
- 실물에 있지만 **넣지 않은 것**: `Fee total`(우리에게 없는 예약 수수료라 늘 $0.00),
  `TRANSACTION DETAILS`(카드 끝자리·승인코드·AID — Chase 단말이 돌려주는 실제 승인 값으로만 채운다),
  같은 영수증 두 장 인쇄(카드 전표가 생기면 추가).
- 바코드가 EAN-13(숫자 티켓)이 아니라 Code 128 인 이유: 우리 영수증 번호 `PH-20260915-0001` 에는
  영문·하이픈이 있다. 화면·매출 탭의 번호와 종이의 번호를 같게 두려고 번호를 그대로 담는다.

## PC 설정 (Epson TM-m30III 기준)

1. **연결**: USB 또는 이더넷.
2. **드라이버**: Epson 지원 페이지에서 TM-m30III 용 Windows 드라이버(Advanced Printer Driver)를 설치한다.
3. **용지**: 드라이버의 인쇄 기본 설정에서 80mm 롤(예: "Roll Paper 80 x 297 mm")을 고른다.
   영수증 뒤로 빈 종이가 길게 나오면 드라이버의 하단 여백 줄이기(용지 절약) 옵션을 켠다.
   항목 이름은 드라이버 버전마다 조금 다르다.
   **글자가 흐리면 인쇄 농도(Print Density)를 올린다** — 프린터 속성 → 인쇄 기본 설정 →
   Advanced / Printer Settings 쪽에 있고, 보통 `Light / Medium / Dark` 또는 `-2 … +2` 단계다.
   농도를 올리면 감열 헤드가 더 오래 달구므로 인쇄가 조금 느려지고 헤드 수명이 줄어든다 —
   읽히는 선에서 한 단계씩만 올린다. 감열지 품질(보존 등급)에 따라서도 진하기가 달라진다.
   영수증 글자 자체도 CSS(`globals.css` 의 `.rc` `-webkit-text-stroke`)에서 굵혀 둔다. 값은 **점(dot)
   기준**으로 잡는다 — 203dpi 헤드에서 점 하나가 0.125mm 다. 처음 쓴 0.025mm(점의 1/5)는 래스터에서
   사라져 아무 효과가 없었고, 지금은 0.1mm(점 0.8개)다. 더 진하게 하려면 이 값을 올리되,
   0.2mm 를 넘기면 3.1mm 글자의 속이 메워져 오히려 읽기 어려워진다.
4. **현금함**: 현금함 선을 프린터의 DK(RJ12) 포트에 꽂고, 드라이버의 현금함 설정에서
   인쇄할 때 여는 옵션을 켠다. 이 방식은 카드 영수증과 재인쇄에도 서랍이 열린다(아래 "한계").
5. **기본 프린터**: Windows 설정 → 프린터 및 스캐너에서 TM-m30III 를 기본 프린터로 두고
   "Windows에서 기본 프린터 관리" 를 끈다.
6. **대화상자 없이 찍기 (권장)**: 계산대 전용 Chrome 바로가기를 만든다.

   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing <계산대 주소>/admin/retail
   ```

   `--kiosk-printing` 은 인쇄 대화상자를 건너뛰고 **Windows 기본 프린터**로 바로 보낸다. Chrome 창이
   이미 하나라도 열려 있으면 플래그가 적용되지 않으니, 모든 Chrome 창을 닫고 이 바로가기로 연다.
   대화상자가 없으므로 기본 프린터가 바뀌면 영수증이 **아무 경고 없이** 사무실 프린터로 나간다.
   5번의 "Windows에서 기본 프린터 관리" 끄기가 이것을 막는 설정이다. 영수증이 안 나오면
   가장 먼저 기본 프린터가 TM-m30III 인지 본다.

   플래그 없이 쓰면 인쇄할 때마다 대화상자가 뜬다. 대상 TM-m30III, 여백 없음,
   배율 기본(100%), 머리글과 바닥글 끔으로 한 번 맞추면 Chrome 이 기억한다.

## 블루투스 프린터 (TM-m30 계열) — 2026-10-18

드라이버 없이 **페어링된 블루투스 TM-m30(II/III)** 에 영수증을 직접 보낸다. 브라우저가 프린터 명령
(ESC/POS)을 만들어 보내므로 인쇄 창이 뜨지 않고, `--kiosk-printing`·기본 프린터·드라이버 절단 설정이
필요 없다.

- **되는 곳**: Chrome 또는 Edge **117 이상**, 맥·윈도 데스크톱. **iPad Safari 는 안 된다**(Web Serial 이
  없다) — iPad 는 인쇄 창(AirPrint)만 쓴다.
- **설정 순서**
  1. 프린터 전원을 켜고 컴퓨터의 블루투스 설정에서 페어링한다(맥: 시스템 설정 → Bluetooth,
     윈도: 설정 → Bluetooth 및 장치). PIN 을 물으면 프린터 기본값(보통 `0000`)을 넣는다.
  2. 계산대(`/admin/retail`) 첫 화면의 **Receipt Printer** 타일을 눌러 `Bluetooth — Epson TM-m30 …` 를 고른다.
  3. **Choose printer** → 창에서 프린터(예: `TM-m30III_xxxxxx`, 직렬 포트로 보인다)를 고른다.
     Chrome 이 이 사이트에 대해 기억하므로 한 번만 하면 된다.
  4. **Print test** 로 로고·글자·바코드·절단을 확인한다.
- 설정은 **그 기기의 브라우저에만** 저장된다. 계산대 PC 마다 따로 한다. 티 시트·매출 탭·레인체크
  인쇄도 같은 설정을 따른다.
- **두 장이 각각 잘린다**(장마다 `GS V` 절단 명령). 드라이버 설정이 필요 없다.
- **현금함은 현금 결제 영수증에서만 열린다**(재인쇄에는 안 열린다). 아래 "한계"의 첫 줄이 이 경로에서는 풀린다.
- 모양: 80mm Font A 한 줄 48자. 내용은 브라우저 인쇄와 **같은 블록**(`receipt.ts`)을
  `frontend/lib/retail/escpos.ts` 가 명령으로 옮긴 것이라 같다. 글꼴만 프린터 글꼴이다.
  로고는 15mm(120점) 흑백으로 바뀌어 찍힌다. 악센트 글자는 코드 페이지 1252 로, 표에 없는 글자(이모지 등)는 `?`.
- **프린터가 응답하지 않으면**(꺼짐·멀어짐·다른 기기에 연결됨) 경고를 띄우고 인쇄 창으로 넘어간다.
  한 번은 자동으로 다시 연결해 본다. 블루투스 프린터는 한 번에 한 기기만 붙으므로, 다른 PC·휴대폰이
  붙어 있으면 그쪽을 끊는다.
- 연결·전송은 `frontend/lib/retail/receiptPrinter.ts`, 설정 화면은 `frontend/components/pos/ReceiptPrinterSetup.tsx`.
  ESC/POS 검사는 아래 `verify-receipt.mjs` 에 같이 있다.

## 계산대에서

- 판매가 끝나면 영수증 화면의 **Print receipt**.
- 장바구니의 **Print receipt after charge** 를 켜 두면 결제될 때마다 자동으로 찍힌다.
  이 설정은 그 PC 브라우저에만 저장된다.
- 지난 영수증은 **Sales** 탭 → 영수증 선택 → **Reprint receipt**. 종이 위쪽에
  `*** REPRINT ***` 가 찍힌다. 환불된 매출에는 `*** REFUNDED ***` 와 사유가 찍힌다.

## 티 시트에서 (그린피·카트) — 2026-09-15

- **전체 결제**(2026-09-15 추가): 상세 패널 머리줄의 **Pay all (인원) 금액** 버튼은 아직 안 낸 사람을
  전부 한 장에 담는다. 버튼의 금액은 세금까지 더한 실제 청구액이라 카드의 Subtotal Due(세전)와 다르다.
  영수증에는 사람마다 그린피·카트 줄이 들어가고 합계는 한 번만 계산한다. 영수증 번호는 `예약번호-ALL`.
  한 사람만 받으려면 그 카드의 Payment 를 쓴다.
- 예약 카드의 **Payment**: 누르면 **영수증 창**이 먼저 열린다(종이에 나갈 것과 같은 화면, 폭 72mm).
  창의 **Pay $금액 & print** 를 눌러야 결제가 기록되고 인쇄가 나간다 — 무엇을 받는지 보고 돈을 받는 순서다.
  Cancel 을 누르면 아무것도 바뀌지 않는다.
  이미 결제한 카드에서 Payment 를 누르면 재인쇄 창이 열리고, **Print again** 은 서버 상태를
  건드리지 않고 `*** REPRINT ***` 가 붙은 영수증만 찍는다.
  결제 취소는 카드 머리의 작은 **Mark unpaid** 로만 한다 — 영수증을 한 장 더 뽑으려다 결제가 지워지지 않게.
- **프린터 선택 창을 없애려면** 위 6번의 `--kiosk-printing` 바로가기로 계산대를 열어야 한다.
  인쇄 대화상자는 브라우저가 띄우는 것이라 페이지 코드로는 없앨 수 없다. 이 바로가기로 열면
  Pay 를 누르는 즉시 **Windows 기본 프린터**로 나간다 — 그래서 기본 프린터가 TM-m30III 여야 한다.
- **Half Cart** 체크: 켜면 서버가 금액을 채운다 — **세전 $19.00**(HST 포함 $21.47), 홀 수·요금제와
  무관하게 한 가지다(2026-09-15 클럽 확인). 이름에 "Cart" 가 든 회원 요금제만 $0 이다.
  금액은 `tee_sheet.py` 의 `cart_fee_for` 한 곳에서 정한다. 칸에서 고칠 수 있고, 결제한 뒤에는 잠긴다.
  카드의 Subtotal Due·시트 통계·일일 리포트 매출에 카트 요금이 들어간다(전부 세전).
  이미 적혀 있던 옛 금액(Chronogolf 에서 들여온 19.47·17.70·9.74 등)은 바뀌지 않는다 —
  $19.00 은 카트를 **새로 켤 때** 채우는 값이다.
- 영수증 모양·로고는 계산대 영수증과 같다. 품목은 실물처럼 `18 Hole Green Fee - Public Senior`,
  `Half Cart (18 Holes) - Public Senior`, 아래 줄 `이름 - Tee Time: 날짜 시각`.
- 영수증 번호: 예약 확인 코드 + 플레이어 id **뒤** 4자(예: `5684-3283-8665`). 바코드도 이 번호다.
  앞에서 자르면 Chronogolf 에서 들여온 예약이 전부 `CHRO-NOGO-CHRO` 로 같아진다(2026-09-15 수정).
  덕분에 들여온 예약의 확인 코드는 Chronogolf 예약 번호의 끝 8자리가 된다.
- 회원처럼 그린피가 $0.00 인 예약도 영수증이 나온다. 금액이 전부 $0.00 인 것은 데이터 그대로다.
- 날짜·시각: 서버가 찍은 결제 시각(`paidAt`, 클럽 현지 시각). 이 기능 전에 결제한 사람은 시각을 몰라
  티 날짜만 찍힌다.
- 결제 수단 줄은 `Payment` 다. Chase 단말 연동 전에는 현금인지 카드인지 기록이 없다.
- 종이는 **서버가 결제를 기록한 뒤에만** 나온다. 오프라인이거나 서버가 거절하면 찍지 않고 카드에
  이유가 뜬다.
- 세금은 브라우저가 계산대와 같은 규칙(`computeTax`)으로 계산한다. 결제 금액을 따로 저장하지 않으므로
  결제 뒤에 그린피를 고치면 재인쇄 영수증도 새 금액을 따른다.

## 확인

- 포맷터·바코드 테스트: `node frontend/scripts/verify-receipt.mjs` (Node 23.6 이상).
  기대값은 손으로 쓴 블록과 손으로 더한 바코드 체크섬이다. 금액이 `Sale` 에서 그대로 옮겨지는지
  (다시 계산하지 않는지)도 여기서 본다.
- 처음 설치할 때: 아무 상품이나 판매 → **Print receipt** → 오른쪽 금액이 종이 밖으로 잘리지
  않는지 본다. 잘리면 ① 드라이버 용지가 80mm 인지, ② Chrome 이 109 이상인지(영수증에만
  여백 0 을 거는 CSS `page` 속성이 그 버전부터 동작한다. 주소창에 `chrome://version`),
  ③ 대화상자로 찍는다면 여백이 "없음" 인지 순서대로 본다.

## 한계와 다음 단계

- **(브라우저 인쇄 경로) 현금함이 모든 인쇄에 열린다.** 블루투스 경로는 현금 결제에만 연다. 드라이버 설정은 인쇄 작업을 구분하지 못한다. 현금 판매에만
  열려면 로컬 브리지가 프린터에 ESC/POS 를 직접 보내야 한다(설계: "Pelham Hills POS·재고 설계"
  Board 03). 브리지는 같은 `receiptBlocks()` 를 받아 블록마다 ESC/POS 명령으로 옮기면 된다 —
  굵게 `ESC E`, 정렬 `ESC a`, 바코드 `GS k`(Code 128, m=73). 바코드는 프린터가 직접 그리므로
  SVG 는 브라우저 인쇄에서만 쓴다.
- **HST 등록번호가 영수증에 없다.** 일정 금액 이상의 영수증에는 구매자가 매입세액공제를
  받을 수 있도록 GST/HST 등록번호가 있어야 한다(기준 금액은 회계사 확인). 포맷터는
  `hstNumber` 를 받을 준비가 돼 있으니, 번호가 정해지면 `CLUB` 에 넣고 `printReceipt.ts` 에서 넘긴다.
- **카드 승인번호가 없다.** Chase 단말 연동("승인 먼저, 기록은 나중") 뒤에 영수증에 추가한다.
- **티 시트의 결제는 아직 직원 표시다.** Chase 연동 뒤에는 승인이 와야 결제로 바뀌고, Mark unpaid 는
  환불 흐름으로 바뀌어야 한다.
- **플레이어별 카트(`cart`)와 예약의 카트 대수(`cartCount`)는 따로 있다.** 합치지 않았다 —
  헬스 체크가 `cartCount` 를 본다. Chronogolf 에서 들여온 예약에는 플레이어별 카트 표시가 없다.
- **카트 요금 $11.50**(export 1,369행)은 어느 요금제인지 몰라 자동 표에 없다. 해당 손님은 칸에서 고친다.
