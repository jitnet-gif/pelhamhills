바로가기 설치

홈 화면에 아이콘으로 붙이기

아이폰 · 아이패드 (Safari)

  1. Safari에서 pelhamhills.vercel.app/admin/scan 열기
  2. 직원 계정으로 로그인
  3. 공유 버튼 → 홈 화면에 추가
  4. 카메라 권한을 물으면 허용

안드로이드 (Chrome)

  1. Chrome에서 같은 주소 열고 로그인
  2. ⋮ 메뉴 → 홈 화면에 추가
  3. Pelham 앱을 설치했다면 아이콘을 길게 누르면 Camera Scan (Staff) 바로가기가 보입니다

아이폰은 화면을 한 번 눌러야 소리가 납니다. 바로가기로 열었는데 소리가 없으면 카메라 화면을 한 번 톡 누르세요.
